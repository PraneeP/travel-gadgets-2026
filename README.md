✈️ Travel Gadgets 2026: Minimalist E-Commerce DashboardThis project is a simulation of an E-commerce website focused on presenting future travel technology gadgets. It features a minimalist design and includes an Admin Dashboard that demonstrates capabilities in data management and data visualization.

This project serves as a Portfolio Showcase, emphasizing proficiency in Frontend Development (React), State Management, Styling (Tailwind CSS), and Data Visualization (Recharts).

🔗 Live DemoYou can view the live website deployed via GitHub Pages here:https://praneep.github.io/travel-gadgets-2026/

✨ Key Features Demonstrated
Feature              Demonstrated Skill
Admin Dashboard      Use of a charting library (Recharts) to display sales and statistics (Data Visualization).
Product Filtering    State Management and logic for real-time category filtering.
Real-time Search     Implementation of JavaScript logic for instant product searching (Debounce Logic).
Responsive Design    Using Tailwind CSS to create a flexible, screen-size adaptable Grid Layout (Mobile-First).
Cart Notification    Utilizing useState and setTimeout to create a Toast Notification (UX/UI Detail).
Deployment           Ability to correctly deploy a complex project (React/Vite) onto GitHub Pages (GitHub Actions).

🛠️ Tech Stack
Frontend Framework: React (Vite)
Styling: Tailwind CSS (Emphasizes speed and Minimalist style)
Data Visualization: Recharts (Used for creating dashboard charts)
Deployment: GitHub Pages & GitHub Actions (Automated CI/CD)
